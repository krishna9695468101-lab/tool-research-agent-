# Assignment 2: Multi-Agent Task with Review

This project implements a multi-agent workflow using LangChain to fulfill the requirements of Assignment 2.

## Task Description
The system consists of two agents working in a single chain without a revision loop:
1. **Agent A (Worker)**: Generates a short product description for a smart coffee mug based on given instructions.
2. **Agent B (Reviewer)**: Evaluates the draft generated by Agent A against strict criteria and returns a structured JSON verdict.

## Agent B Approval Criteria
Agent B explicitly checks if the description:
1. Is under 60 words.
2. Explicitly mentions "temperature control".
3. Explicitly mentions "battery life".

If any of these fail, Agent B rejects the draft with specific reasons. Otherwise, it is approved.

## Deliverables Included
- `main.py`: The code implementing both agents.
- `transcript_1.txt`: A run where Agent B approves the output.
- `transcript_2.txt`: A run where Agent B rejects the output (forced by instructing Agent A to omit "battery life").

## How to Run
Ensure dependencies are installed from the root directory:
```bash
pip install -r ../assignment-1/requirements.txt
```

Set your API Key:
```bash
$env:GOOGLE_API_KEY="your_key"
```

Run the script:
```bash
python main.py
```
